阅流 NovelFlow 隐私政策

Chrome 扩展隐私说明 · 中文

生效日期：2026-11-01
适用版本：1.0.6 及以后版本，直至本页面更新

1. 单一用途

阅流用于把用户当前有权访问的网页小说正文整理为本地阅读视图。扩展只在用户点击工具栏图标后运行，不监听或修改其他浏览活动。

2. 处理的数据

  • 当前网页内容：为提取正文、识别下一页或下一章，扩展会读取用户主动开启阅读器的页面，以及同一网站内由页面链接指向的后续章节。
  • 当前网页地址：用于判断站点规则、请求同源后续页面、防止翻页循环，并在本机保存阅读位置。
  • 设置和阅读进度：主题、字号、行距、宽度、滚动速度、站点级 CSS 选择器和阅读位置保存在浏览器本机的 chrome.storage.local。

3. 不收集、不出售、不共享

扩展不把正文、网址、浏览历史、设置或阅读进度上传给开发者或任何第三方；不包含账号系统、广告、统计、远程脚本、远程规则更新或数据出售/共享服务。

4. 网络访问

扩展只请求当前小说网站及页面中可靠链接所指向的同源页面。浏览器会按正常网页会话规则处理登录状态和同源 cookie；扩展不直接读取、记录或修改 cookie。跨域章节、跨域 iframe、登录、VIP、购买、订阅、验证码、安全验证和限流不会被绕过。

5. 权限用途

  • activeTab：仅在用户点击扩展图标后临时授予当前标签页访问权。
  • scripting：把随扩展打包的本地阅读器脚本按需注入当前标签页。
  • storage：在本机保存阅读设置、站点选择器和阅读位置。

6. 保留与删除

设置和阅读进度保留在本机浏览器存储中，直到用户清除扩展数据或卸载扩展。正文不会被持久存储。用户可通过 Chrome 扩展管理页移除扩展，以清除其本地存储。

7. 儿童隐私

扩展不主动收集任何人的个人信息，也不面向儿童专门收集数据。

8. 政策更新

功能或数据处理方式发生实质变化时，本页面会更新生效日期，并在适用的 Chrome Web Store 商品详情中说明。

9. 联系

隐私或安全问题请通过 GitHub Issues 联系维护者。请勿在公开 Issue 中粘贴账号凭据、cookie 或受限正文。

NovelFlow Privacy Policy

Chrome extension privacy notice · English

Effective date: November 1, 2026

NovelFlow is a single-purpose extension that turns the novel chapter a user is authorized to view into a local immersive reading view. It runs only after the user clicks the toolbar icon.

The extension reads the current page and same-origin linked chapter pages to extract text and navigate. The current URL is used for site matching, safe same-origin requests, loop prevention, and locally stored progress. Reading preferences, site selectors, and progress are stored in chrome.storage.local. Article text, URLs, browsing history, settings, and reading progress are not uploaded to the developer or any third party.

NovelFlow contains no account system, advertising, analytics, remote code, remote rule updates, or data sale/sharing. It does not bypass login, VIP, purchase, subscription, CAPTCHA, security checks, rate limits, or cross-origin browser boundaries. The browser handles normal same-site cookies; the extension does not directly read, record, or modify cookies.

Permissions are limited to activeTab for temporary access after a user click, scripting for injecting the bundled local reader, and storage for local preferences and reading position. Local data remains until the user clears extension data or uninstalls the extension.

Contact the maintainer through GitHub Issues for privacy or security questions.
