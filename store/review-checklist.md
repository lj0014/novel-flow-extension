# Chrome Web Store 首次上架检查单

## 账号与费用

- [ ] 使用要长期维护扩展的 Google 账号登录 Developer Dashboard。
- [ ] 按后台要求开启两步验证。
- [ ] 接受 Chrome Web Store Developer Agreement。
- [ ] 完成开发者身份和联系信息验证。
- [ ] 支付一次性开发者注册费。官方常见价格为 US$5；适用税费和最终金额以后台账单页为准。

## 上传包

- [ ] 上传 `NovelFlow_1.0.6_ChromeWebStore.zip`。
- [ ] 确认 ZIP 根目录直接包含 `manifest.json`。
- [ ] 确认版本为 1.0.6、Manifest V3。
- [ ] 确认包内只有运行时文件，不含 tests、node_modules、README 或外层文件夹。

## 商店素材

- [ ] 128×128 商店图标，内容主体约 96×96 并保留 16 px 透明边距。
- [ ] 至少一张 1280×800 截图，最多 5 张。
- [ ] 440×280 小型宣传图。
- [ ] 图片无未授权版权内容、虚假评价、误导按钮或未经证实的排名。

## 商品信息

- [ ] 名称：阅流 · 小说沉浸阅读。
- [ ] 简短说明和详细介绍使用 `store-listing-zh-CN.md`。
- [ ] 分类：Productivity；语言：简体中文。
- [ ] 主页、支持链接和隐私政策 URL 可公开访问且无登录限制。

## 隐私与权限

- [ ] 按 `privacy-practices.md` 如实披露网页内容、当前网址和本地设置的用途。
- [ ] 权限理由使用 `permission-justifications.md`。
- [ ] 证明单一用途、最小权限、用户数据有限使用和无远程代码。
- [ ] 声明不绕过登录、VIP、购买、订阅、验证码、安全验证、限流或跨域限制。
- [ ] 不宣传“去广告”“免费看 VIP”或类似可能被视为绕过付费的内容。

## 提交审核

- [ ] 确认目标地区、可见性（Public/Unlisted/Private）和发布时机。
- [ ] 检查所有链接、截图、描述和付款信息。
- [ ] 提交审核。
- [ ] 在开发者后台和注册邮箱关注审核问题，及时提供复现说明。
