# Chrome Web Store 商品详情（简体中文）

## 名称

阅流 · 小说沉浸阅读

## 简短说明（132 字符以内）

把当前网页小说整理为护眼、清爽的沉浸阅读界面，支持自动滚动、连续续页续章、阅读进度和站点选择器。正文在本地处理，不上传阅读数据。

## 详细介绍

阅流会把你当前正在阅读、且有权访问的网页小说正文整理成干净、居中、适合长时间阅读的页面。点击 Chrome 工具栏中的阅流图标即可在原文之上开启阅读器，退出后恢复原网页。

主要功能：

- 护眼绿、纸张和深色三种主题，可调整字号、行距、正文宽度和滚动速度。
- 自动滚动和本地阅读进度，手动滚动时自动暂停。
- 识别同章下一页和后续章节，连续拼接时保持阅读位置。
- 同一章节多页只显示一个标题；相同地址、相同正文、自指链接和重复请求会自动停止。
- 正文识别结合站点规则、文字量、段落数量和链接密度，并提供按域名保存的自定义 CSS 选择器。
- 兼容常见小说建站模板，包括杰奇／BookText、PTCMS、YGBOOK、狂雨、WMCMS、MCCMS、novel-plus、小浣熊小说 CMS、船说、YiDu Novel、EnovelCMS、经典笔趣阁、快眼看书和 Booksky 转码模板。
- 点击扩展图标后才读取当前标签页；只有 `activeTab`、`scripting` 和 `storage` 三项权限，不申请全站常驻访问。

边界说明：

- 只处理原站已经返回、当前用户有权访问的内容。
- 不绕过登录、VIP、购买、订阅、验证码、安全验证、限流或跨域浏览器限制。
- 不伪造没有可靠地址的下一章 URL；正文为空、受限或验证失败时停止并提供原站入口。
- “笔趣阁”“快眼看书”等名称下存在大量不同源码和镜像，无法保证每个镜像和每次改版始终命中；正文识别错误时可用“站点适配”填写当前网站的 CSS 选择器。

隐私：

正文提取、排版和翻页在浏览器本地完成。扩展不上传正文、浏览历史、设置或阅读进度，不包含广告、统计、远程脚本或远程规则更新。详细说明见隐私政策。

## 单一用途说明

将用户当前有权访问的中文网页小说整理成本地沉浸阅读视图，并支持同一网站内可靠的续页与续章阅读。

## 审核备注

- Manifest V3，最低 Chrome 109。
- 运行权限仅 `activeTab`、`scripting`、`storage`。
- 无常驻 `content_scripts`、无 `host_permissions`。
- 无远程代码、无 eval、无外部脚本、无遥测。
- 用户点击扩展图标后才注入本地 `content.js`。
- 测试、复现脚本和原始结果在公开 GitHub 仓库。
