# 权限与站点访问理由

## `activeTab`

用户点击扩展图标后临时访问当前标签页，用于在该小说章节页开启本地阅读器。此权限避免申请全站常驻访问，也避免后台读取无关网页。

## `scripting`

`background.js` 在用户点击图标后调用 `chrome.scripting.executeScript`，注入扩展自带的 `content.js`，创建 Shadow DOM 阅读器。脚本随扩展包分发，不加载或执行远程代码。

## `storage`

使用 `chrome.storage.local` 在本机保存阅读主题、字号、行距、正文宽度、滚动速度、站点级 CSS 选择器和阅读位置，以便下次使用。数据不上传。

## 宿主站点访问

商店清单不申请 `host_permissions`。当前页面访问来自用户点击产生的 `activeTab` 临时授权；读取后续章节时，后台代码只接受扩展内容脚本的请求，并校验目标页面来源、响应型别、响应大小和重定向后的最终来源。

## 为什么不需要常驻站点权限

扩展没有声明 `content_scripts`，也不在后台扫描用户正在访问的网站。只有用户明确点击“阅流”图标时才启动，因此不需要全站自动访问权限。
