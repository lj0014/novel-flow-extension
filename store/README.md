# Chrome Web Store 提交材料

本目录用于准备 NovelFlow 1.0.6 的 Chrome Web Store 首次提交。

## 文件

- `NovelFlow_1.0.6_ChromeWebStore.zip`：商店上传包，`manifest.json` 位于 ZIP 根目录。
- `store-listing-zh-CN.md`：商品名称、简短说明、详细介绍和链接。
- `privacy-practices.md`：用户数据披露建议。
- `permission-justifications.md`：权限与站点访问理由。
- `review-checklist.md`：账号、素材、政策与审核检查项。
- `release-notes-1.0.6.md`：首次审核版本说明。
- `screenshots/reader-1280x800.png`：商店截图。
- `promo-440x280.png`：小型宣传图。
- `store-icon-128.png`：带透明边距的商店图标。

## 首次提交状态

制品和文案可以准备完整；Google 账号登录、开发者协议、身份/联系方式确认、两步验证以及一次性注册费必须由账号持有人完成。账单金额和地区税费以后台显示为准。

## 正式提交前

1. 登录 [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole/)。
2. 完成开发者注册与付款。
3. 上传 `NovelFlow_1.0.6_ChromeWebStore.zip`。
4. 按本目录文案填写 Store listing、Privacy practices 和权限理由。
5. 确认公开发布范围与内容。
6. 提交审核。
